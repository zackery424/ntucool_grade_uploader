# NTU COOL 成績與附件小幫手

> A Chrome extension that auto-fills grades and uploads annotated PDFs on NTU COOL (Canvas) SpeedGrader, matched by student ID from an Excel sheet and a local folder. Unofficial, personal-use tool — see Disclaimer below.

在 NTU COOL（台大採用的 Canvas LMS）的 **SpeedGrader**（作業批改模式）頁面上，加一個懸浮控制面板：
讀取你批改完的 **Excel 成績表** 與存放 **已批改 PDF** 的資料夾，用學號自動比對，
一鍵把成績填進去、把對應的 PDF 掛成附件並送出評論，省去手動一個一個找檔案、複製貼上分數的時間。

不是官方工具，也沒有對外部伺服器傳送任何資料——所有比對、上傳都是在你自己的瀏覽器裡、
用你已登入的帳號完成。詳見下方[隱私與安全](#隱私與安全)、[免責聲明](#免責聲明)。

## 功能

- 讀取 `.xlsx` / `.xls` / `.csv` 成績表，自動猜「學號欄位」與「成績欄位」，猜錯可手動改選
- 讀取一整個資料夾的 PDF，用**檔名裡的學號**自動比對每份檔案屬於哪位學生
- 即時顯示 SpeedGrader 目前選到的學生，以及比對到的成績／PDF，比對不到會明確標示「找不到」
- 可選擇「只填成績」「只掛附件（不送出，留給你手動確認）」或「填成績＋掛附件＋直接送出」
- 支援批次處理：依序跑過所有「成績與 PDF 都比對成功」的學生，中途出錯會自動停止
- 所有邏輯都在瀏覽器本機執行（content script），不會把 Excel、PDF 或成績資料送到 NTU 以外的任何地方

## 安裝方式

目前沒有上架 Chrome 線上應用程式商店，需要用「載入未封裝項目」的方式手動安裝：

1. 下載或 clone 這個 repository 到你電腦上一個固定位置（之後不要刪除或搬動這個資料夾）。
2. 打開 Chrome，網址列輸入 `chrome://extensions`。
3. 右上角打開「**開發人員模式**」。
4. 點「**載入未封裝項目**」，選擇本 repository 的資料夾（含 `manifest.json` 那一層，
   **不要**選 zip 檔本身，要先解壓縮）。
5. 打開任何一個 NTU COOL 的 SpeedGrader 頁面
   （網址長得像 `https://cool.ntu.edu.tw/courses/12345/gradebook/speed_grader?assignment_id=...`），
   畫面右上角就會出現「NTU COOL 成績小幫手」面板。

> 需要 Chrome（或其他 Chromium 系瀏覽器，如 Edge）114 版以上。

## 使用步驟

1. **① 成績 Excel / CSV**：選擇批改後的成績表。載入後會出現「學號欄位」「成績欄位」兩個下拉選單，
   會自動猜一次，猜錯就手動改選正確的欄位。
2. **② 已批改 PDF 資料夾**：選擇存放所有批改完 PDF 的資料夾。小幫手會用檔名裡的學號自動比對，
   對不到的檔案會列在「找不到學號」清單，需要手動確認檔名。
3. **③ 目前學生**：面板即時顯示 SpeedGrader 目前選到的學生、比對到的成績、比對到的 PDF 檔名；
   顯示「找不到」代表 Excel 或資料夾裡沒有對應資料。
4. **④ 評論文字**：可留空，也可以填一句制式評語（例如「已批改，請見附件」），送出附件時一併附上。
5. 操作按鈕：

   | 按鈕 | 動作 |
   | --- | --- |
   | 只填成績 | 只把成績打進成績欄位（模擬輸入＋按 Enter），不動評論／附件 |
   | 只附加 PDF | 把 PDF 掛到附件欄位，但**不會**按下「提交」，留給你自己檢查後手動送出 |
   | 填成績＋附加並送出 | 三個動作一次做完：填成績 → 掛附件 → 按提交 |
   | 成功送出後自動跳下一位（勾選框） | 「填成績＋附加並送出」成功後自動按「下一位」 |
   | 批次處理剩下所有已比對到的學生 | 依序自動處理所有成績與 PDF 都比對成功的學生，中途失敗會停下 |

   **強烈建議先用前三顆按鈕手動測試 1～2 位學生、確認流程與畫面都正確，再使用批次按鈕。**

## 學號與欄位比對規則

- 學號格式：目前只認得台大常見的「**1 個英文字母 ＋ 8 碼數字**」（例如 `B12505033`、`R14525017`），
  大小寫皆可，會自動轉大寫比對。
- Excel 欄位自動猜測：欄名含「學號 / student id / 帳號」視為學號欄；
  含「成績 / 分數 / 得分 / score / grade / points / total / 合計 / 總分」視為成績欄；
  兩者都沒猜到時，會退而挑「最右邊有資料的欄位」當成績欄（例如很多成績單習慣把 `Total` 放最後一欄）。
  猜錯了都可以直接在面板上手動改選。
- PDF 檔名比對：只要檔名裡的任何位置出現學號格式，就會被抓出來對應該生，
  跟檔名其他部分（姓名、日期、字尾 `#`…）無關。同一位學生若有多個檔案符合，會取讀取到的最後一個。

## 疑難排解

- **「載入未封裝項目」就報錯**：確認選的是解壓縮後的資料夾，不是 zip 檔本身；
  也確認資料夾裡有 `manifest.json`。
- **擴充功能裝上了，但進 SpeedGrader 沒看到面板**：確認網址符合
  `https://cool.ntu.edu.tw/courses/*/gradebook/speed_grader*` 這個格式；
  也可能是頁面在小幫手載入前就已經完全渲染完成，重新整理一次通常就會出現。
- **一直顯示「找不到」**：多半是學號格式不吻合（例如 Excel 裡學號前後多了空白、
  PDF 檔名裡學號被拆成兩段），可以先用少量資料測試、確認格式一致。
- **點按鈕出現「找不到 OO 按鈕」的錯誤**：代表 NTU COOL 那次改版動到了頁面結構，
  需要回來更新 `content.js` 裡對應的元素選擇器（selector）。

## 已知限制

- 目前只支援台大標準學號格式；校外生帳號（例如 `external_...`）或其他學校的學號格式無法自動比對。
- PDF 資料夾在頁面重新整理後需要重新選擇一次（瀏覽器安全限制，檔案內容不會被記住），
  但成績 Excel 的比對結果會自動保留。
- 完全依賴 NTU COOL 目前（Canvas）頁面的 HTML 結構，官方改版有可能讓小幫手失效。
- 「批次處理」目前是透過畫面上的「下一位」按鈕依序移動，如果 SpeedGrader 的排序邏輯或分頁行為改變，
  批次功能可能需要相應調整。

## 隱私與安全

- 不會請求任何跟 NTU COOL 帳密、Cookie 相關的權限；擴充功能就是操作你目前已登入分頁上的畫面元素。
- Excel／PDF 檔案只會被讀進瀏覽器分頁的記憶體，成績比對結果（不含 PDF 檔案本身）
  會用 `chrome.storage.local` 存在你自己電腦上，方便重新整理頁面後還在，除此之外不會寫到別的地方。
- 沒有任何網路請求會被送到 NTU COOL 以外的網域；唯一內建的第三方程式碼是離線打包的
  [SheetJS](https://github.com/SheetJS/sheetjs)（用來讀 Excel），完全不連網。
- 這個工具**會**直接對 NTU COOL 送出真實的成績與評論資料，這部分無法避免（本來就是它的功能），
  請務必自行核對後再送出，尤其是使用批次功能之前。

## 檔案結構

```
manifest.json           擴充功能設定檔（Manifest V3）
content.js              主要邏輯：面板 UI、Excel/PDF 解析、學號比對、自動填寫與上傳
net_spy.js              注入到頁面主世界，監看「送出評論/附件」的真實網路回應，用來準確判斷成功/失敗原因
lib/xlsx.full.min.js    讀取 Excel/CSV 用的 SheetJS（離線打包，未修改）
icons/                  擴充功能圖示

THIRD_PARTY_LICENSES.txt SheetJS 的 Apache-2.0 授權全文與出處
```
