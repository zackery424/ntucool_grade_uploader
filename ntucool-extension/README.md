# NTU COOL 成績與附件小幫手

在 NTU COOL（Canvas）的 **SpeedGrader**（作業批改模式）頁面右側，加一個懸浮小面板，
依你提供的 Excel 成績表與資料夾裡已批改的 PDF，用學號自動比對、填入成績、上傳附件並送出評論。

所有動作都是在你自己瀏覽器裡、用你已登入的 NTU COOL 帳號完成，Excel／PDF 也只留在你的
電腦記憶體裡，這個擴充功能不會把任何資料傳到 NTU 以外的伺服器。

## 安裝方式（載入未封裝的擴充功能）

1. 解壓縮這個資料夾到你電腦上一個固定位置（之後不要刪除或搬動）。
2. 打開 Chrome，網址列輸入 `chrome://extensions`。
3. 右上角打開「開發人員模式」。
4. 點「載入未封裝項目」，選擇這個資料夾（含 `manifest.json` 那一層）。
5. 之後打開任何一個 NTU COOL 的 SpeedGrader 頁面
   （網址長得像 `https://cool.ntu.edu.tw/courses/12345/gradebook/speed_grader?assignment_id=...`），
   畫面右上角就會出現「NTU COOL 成績小幫手」的面板。

## 使用步驟

1. **① 成績 Excel / CSV**：選擇你批改後的成績表（.xlsx / .xls / .csv）。
   載入後面板會出現「學號欄位」「成績欄位」兩個下拉選單，會自動猜一次，
   如果猜錯了（例如欄位名稱不是「學號」「成績」），手動改選正確的欄位即可。
2. **② 已批改 PDF 資料夾**：選擇存放所有批改完 PDF 的資料夾。
   小幫手會用「檔名裡的學號」（例如 `B12345678`、`R14525017` 這種 1 個英文字母＋8 碼數字的格式）
   來自動比對每份 PDF 屬於哪位學生。**請確保你的 PDF 檔名裡有包含完整學號**，
   否則該檔案會被列在「找不到學號」名單中，需要手動改檔名。
3. **③ 目前學生**：面板會即時顯示 SpeedGrader 目前選到的學生、比對到的成績、比對到的 PDF 檔名。
   如果顯示「找不到」，代表 Excel 或資料夾裡沒有對應的資料，請先確認學號有沒有打錯或格式不一致。
4. **④ 評論文字**：可留空，也可以填一句制式評語（例如「已批改，請見附件」），
   送出附件時會一起附上這段文字。
5. 操作按鈕：
   - **只填成績**：只把成績填進成績欄位（模擬打字＋按 Enter），不會動評論／附件。
   - **只附加PDF**：把 PDF 掛到評論欄位的附件欄位，但**不會**按下 NTU COOL 的「提交」，
     讓你可以自己再檢查一次再手動送出。
   - **填成績＋附加並送出**：三個動作一次做完（填成績 → 附加PDF → 按提交）。
   - **成功送出後自動跳下一位**：勾選後，「填成績＋附加並送出」成功時會自動幫你按「下一位」。
   - **批次處理剩下所有已比對到的學生**：會依序（透過 SpeedGrader 的「下一位」）
     自動處理所有「成績與PDF都比對成功」的學生，中途若失敗會停下來。
     **強烈建議先用前面的按鈕手動測試 1～2 位學生、確認流程與畫面都正確後，再使用這個批次按鈕。**

## 重要提醒

- 這個工具會**直接對 NTU COOL 上真實的學生成績與評論送出資料**，一旦送出不容易復原，
  請先在少數幾位學生身上測試過，確認「成績有沒有填對」「附件有沒有對到人」都正常之後，
  再放心大量使用。
- 頁面重新整理後，PDF 資料夾需要重新選擇一次（瀏覽器安全限制，檔案內容不會被記住），
  但成績 Excel 的比對結果會自動幫你保留。
- 如果 NTU COOL 改版導致頁面結構變動，小幫手可能會抓不到欄位、跳出「找不到 XX 按鈕」的錯誤，
  屆時需要更新程式碼裡對應的元素代碼（selector）。
- 目前只認得「1 個大寫英文字母＋8 碼數字」這種台大學號格式（例如 B12505033、R14525017）。
  如果有校外生或特殊格式的學號比對不到，可以先手動把該位學生的 PDF 檔名／Excel 學號欄
  改成小幫手看得懂的格式，或請我再幫你調整比對規則。

## 檔案結構

```
manifest.json         擴充功能設定檔
content.js            主要邏輯（面板 UI、比對、自動填寫/上傳）
lib/xlsx.full.min.js  讀取 Excel/CSV 用的開源函式庫（SheetJS，離線打包，不會連外）
icons/                擴充功能圖示
```
